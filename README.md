# 夜宴地圖 · 赤月計算機

夜宴成員使用的獨立地圖與赤月餐廳點餐計價工具。採用紅黑主題，支援電腦及手機，無須後端或資料庫。

## 使用方式

- 線上版：[開啟夜宴地圖](https://haru2017055.github.io/yeyan-map/)；[直接開啟赤月計算機](https://haru2017055.github.io/yeyan-map/#calculator)。
- 離線版：下載完整專案，解壓縮後使用 Chrome 或 Edge 開啟 `index.html`。
- 上方可切換「夜宴地圖」與「赤月計算機」。

## 夜宴地圖

- 搜尋地點、調整地圖、顯示名稱。
- 自行新增地標，並編輯、刪除或直接更換位置。
- 一般地標、黃色點、綠色點分開儲存。
- 黃色與綠色點各自匯入／匯出 JSON，不影響其他顏色的點。

## 資料儲存與分享

新增地標、地標修改及未結訂單只儲存在目前瀏覽器，不會自動上傳 GitHub，也不會與其他員工同步。需分享地標時，請使用頁面上的匯出／匯入功能。

離線網頁與線上網站使用不同儲存空間；第一次改用線上版，請先在原本頁面匯出要保留的地標，再到線上版匯入。更換瀏覽器、裝置或網址也可能需要重新匯入。請勿把私人匯出紀錄提交到公開儲存庫。

## GitHub Pages

此專案為靜態網站，入口為根目錄 `index.html`。Pages 使用 `main` 分支的根目錄 (`/`)，不需建置指令。

保留 `assets` 及所有 CSS／JS 檔案的相對位置。原始 `police_map` 為另一個專案，這份網站獨立維護。
